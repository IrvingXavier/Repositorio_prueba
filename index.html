Este proyecto no es solo código, es un laboratorio de aprendizaje:

  • Experimentar:Crear archivos, relacion entre repocitorios (local y remoto)
  • Documentar: Guardar configuraciones útiles de la terminal.

Herramienta Uso Principal

Comandos Esenciales

Copia y pega estos comandos en tu terminal:

bash 
# Clonar un repositorio remoto
git clone https://github.com/usuario/repo.git

# Ver el estado actual de los archivos
git status

# Sincronizar cambios desde GitHub
git pull origin main

# Preparar archivos para el commit
git add .

# Guardar cambios con un mensaje descriptivo
git commit -m "Mensaje claro y conciso"

# Subir cambios a GitHub
git push origin main

# Ver el historial de commits
git log --oneline --graph
